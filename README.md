# Reliance-Industries-Stock-Forecast
Developed a stock price prediction model for Reliance Industries using historical data. Applied data preprocessing, feature engineering, and machine learning techniques to forecast future prices and analyze trends.

# 📈 Stock Price Prediction – Reliance Industries

## 🚀 Project Overview

This project aims to predict the future stock prices of Reliance Industries using historical stock data and machine learning techniques. The model analyzes past trends and patterns to forecast stock prices for the next 30 days.

---

## 🎯 Objective

* Predict stock prices for the next 30 days
* Analyze short-term and long-term trends
* Build accurate machine learning models

---

## 📊 Dataset

* Source: Yahoo Finance
* Time Period: 2015 – 2022
* Features:

  * Open
  * High
  * Low
  * Close
  * Volume

---

## ⚙️ Workflow

### 1. Data Collection

* Collected historical stock data using `yfinance`

### 2. Data Preprocessing

* Handled missing values
* Converted date column to datetime
* Sorted data chronologically

### 3. Exploratory Data Analysis (EDA)

* Visualized stock price trends
* Identified patterns and volatility
* Compared different price features

### 4. Feature Engineering

* Moving averages (MA10, MA50)
* Daily returns
* Lag features

### 5. Model Building

Implemented multiple machine learning models:

* Linear Regression
* Random Forest Regressor
* ARIMA (time series model)

### 6. Model Evaluation

Metrics used:

* Mean Absolute Error (MAE)
* Root Mean Squared Error (RMSE)

### 7. Forecasting

* Predicted stock prices for the next 30 days
